# SáchViệt – Website kinh doanh sách, truyện

Bài tập môn Thiết kế Web – Trường Đại học Mở Hà Nội, Khoa Công nghệ thông tin.
Sinh viên: Phùng Thị Quyên.

- `1_Website/` – mã nguồn website (HTML, CSS, JavaScript). Mở `1_Website/index.html` để xem.
- `2_Thiet-ke/` – sơ đồ bố cục, sơ đồ website, ảnh giao diện.
- `3_Bao-cao-PhungThiQuyen.docx` – báo cáo.

Ảnh bìa sách lấy từ Open Library, chỉ dùng cho mục đích học tập.
